# Third-party assets

This repository contains source code written for this project and a generated toy dataset only.

It does not redistribute:

- CLIP model weights
- Flickr8k images or captions
- CUDA or PyTorch binaries

The default runtime model identifier is `openai/clip-vit-base-patch32`. Model weights are downloaded by the Transformers library on the user's machine and remain subject to their original terms.

Flickr8k must be obtained separately from a legitimate source and used according to its applicable terms.
